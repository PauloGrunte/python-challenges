# Build the Tower of Hanoi - freeCodeCamp
This repository contains my solution for the "Build the Tower of Hanoi" project, required to complete the Scientific Computing with Python Certification at freeCodeCamp.

📝 **Description**
The goal of this project is to solve the classic mathematical puzzle known as the Tower of Hanoi. The puzzle consists of three rods and a number of disks of different diameters. The objective is to move all the disks from the first rod to the last one, following strict rules: moving only one disk at a time, only moving the topmost disk, and never placing a larger disk on top of a smaller one.

🎯 **Objective**
Fulfill all the user stories provided by freeCodeCamp and make all the automated tests pass to complete the lab.

✨ **Features**
*   **hanoi_solver Function:** Takes an integer representing the total number of puzzle disks as an argument.
*   **Optimal Solution (Recursion):** Solves the puzzle mathematically following the rules in exactly 2ⁿ - 1 moves, where n is the total number of disks.
*   **State Tracking:** Represents the rods as lists of integers (with 1 being the smallest disk) and keeps track of the disks' positions accurately during the recursive calls.
*   **Formatted Output:** Returns a single string with all the moves made to solve the puzzle, including the initial layout. Each move is displayed on a new line with each rod separated by a space.

# Construir a Torre de Hanói (Build the Tower of Hanoi) - freeCodeCamp
Este repositório contém a minha solução para o projeto "Construir a Torre de Hanói" (Build the Tower of Hanoi), necessário para concluir a certificação em Computação Científica com Python do freeCodeCamp.

📝 **Descrição**
O objetivo deste projeto é resolver o clássico quebra-cabeça matemático conhecido como Torre de Hanói. O quebra-cabeça consiste em três hastes e um número de discos de diferentes diâmetros. O objetivo é mover todos os discos da primeira haste para a última, seguindo regras estritas: mover apenas um disco por vez, mover apenas o disco do topo e nunca colocar um disco maior sobre um menor.

🎯 **Objetivo**
Cumprir todas as user stories fornecidas pelo freeCodeCamp e fazer todos os testes automatizados passarem para completar o laboratório.

✨ **Funcionalidades**
*   **Função hanoi_solver:** Recebe um número inteiro representando o número total de discos do quebra-cabeça como argumento.
*   **Solução Otimizada (Recursão):** Resolve o quebra-cabeça matematicamente seguindo as regras em exatamente 2ⁿ - 1 movimentos, onde n é o número total de discos.
*   **Rastreamento de Estado:** Representa as hastes como listas de inteiros (sendo 1 o menor disco) e mantém o controle preciso das posições dos discos durante as chamadas recursivas.
*   **Saída Formatada:** Retorna uma string única com todos os movimentos realizados para resolver o quebra-cabeça, incluindo a disposição inicial. Cada movimento é exibido em uma nova linha com cada haste separada por um espaço.
