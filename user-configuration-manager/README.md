# User Configuration Manager

A simple Python script to manage user preferences (like theme and volume) using dictionaries. This project was built as a practice challenge from **freeCodeCamp**.

## ⚙️ Features

* **Add (`add_setting`)**: Adds a new configuration. It converts keys to lowercase to prevent duplicates.
* **Update (`update_setting`)**: Changes the value of an existing setting.
* **Delete (`delete_setting`)**: Removes a specific setting from the dictionary.
* **View (`view_settings`)**: Displays all current settings clearly, capitalizing the first letter of each key.
