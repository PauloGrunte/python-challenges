# Budget App - freeCodeCamp

This repository contains my solution for the **"Build a Budget App"** project, required to complete the Scientific Computing with Python Certification at [freeCodeCamp](https://www.freecodecamp.org/).

## 📝 Description
The goal of this project is to build a simple budget application that tracks spending across different categories (e.g., Food, Clothing, Entertainment). It allows users to deposit, withdraw, and transfer funds between categories. Additionally, the application generates a visual representation (a bar chart) showing the relative percentage of spending in each category.

## 🎯 Objective
Fulfill all the user stories provided by freeCodeCamp and make all the automated tests pass to complete the lab.

## ✨ Features
* **Instantiate Categories:** Create budget categories with a ledger to track transactions.
* **Deposit:** Add funds to a category with an optional description.
* **Withdraw:** Remove funds from a category if the balance is sufficient.
* **Get Balance:** Check the current balance of a budget category.
* **Transfer:** Move funds from one category to another safely.
* **Formatted Output:** Printing the category object displays a cleanly formatted receipt of the ledger.
* **Spend Chart:** A standalone function that takes a list of categories and returns a string representing a bar chart of the percentage spent in each category.

# Aplicativo de Orçamento (Budget App) - freeCodeCamp

Este repositório contém a minha solução para o projeto **"Construir um app de orçamento"** (Build a Budget App), necessário para concluir a certificação em Computação Científica com Python do [freeCodeCamp](https://www.freecodecamp.org/).

## 📝 Descrição
O objetivo deste projeto é construir um aplicativo simples de orçamento que rastreia os gastos em diferentes categorias (ex: Alimentação, Vestuário, Lazer). Ele permite aos usuários depositar, sacar e transferir fundos entre categorias. Além disso, o aplicativo gera uma representação visual (um gráfico de barras) mostrando a porcentagem relativa de gastos em cada categoria.

## 🎯 Objetivo
Cumprir todas as *user stories* fornecidas pelo freeCodeCamp e fazer todos os testes automatizados passarem para completar o laboratório.

## ✨ Funcionalidades
* **Instanciar Categorias:** Criar categorias de orçamento com um livro-razão (ledger) para rastrear transações.
* **Depósito (Deposit):** Adicionar fundos a uma categoria com uma descrição opcional.
* **Saque (Withdraw):** Remover fundos de uma categoria se o saldo for suficiente.
* **Verificar Saldo (Get Balance):** Checar o saldo atual de uma categoria.
* **Transferência (Transfer):** Mover fundos de uma categoria para outra de forma segura.
* **Saída Formatada:** Imprimir o objeto da categoria exibe um recibo formatado e alinhado do extrato.
* **Gráfico de Gastos (Spend Chart):** Uma função independente que recebe uma lista de categorias e retorna uma string representando um gráfico de barras com a porcentagem gasta em cada categoria.
